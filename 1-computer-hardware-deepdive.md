1. Introduction to Computer Hardware
Computer hardware refers to the physical components of a computer system that we can see and touch.

Hardware is responsible for processing data, storing information, displaying output and performing various computing operations.

A computer system consists of several important hardware components:
1. Motherboard
2. CPU (Central Processing Unit)
3. RAM (Random Access Memory)
4. Storage devices (HDD and SSD)
5. Power Supply Unit (PSU)
6. Input and Output devices
7. Peripheral devices and expansion cards
These components work together to perform computing operations.
2. Motherboard
The motherboard is the main printed circuit board (PCB) of a computer. It connects all the major hardware components and allows them to communicate with each other.

It acts as the central communication platform of a computer.
Major components connected to the motherboard
- CPU socket
- RAM slots
- Storage connectors
- Expansion slots
- BIOS/UEFI firmware
- CMOS battery
- USB and other I/O ports
- Power connectors
- Ethernet (RJ45) port
Important: The motherboard does not necessarily contain all these components physically. It provides the sockets, connectors and circuits required to connect them.
3. CPU (Central Processing Unit)
The CPU is known as the brain of the computer. It is responsible for executing instructions, performing calculations and controlling different operations of a computer.
3.1 CPU Cores
A CPU can have multiple cores. A core is an individual processing unit capable of executing instructions.

Common CPU configurations include:
- 2-core (Dual Core)
- 4-core (Quad Core)
- 6-core (Hexa Core)
- 8-core (Octa Core)
- 12-core
- 16-core and above
Advantages of multiple cores:
1. Better multitasking.
2. Improved performance in multi-threaded applications.
3. Faster execution of parallel tasks.
4. Better performance in video editing, rendering and other demanding workloads.
For example, an 8-core processor can handle multiple processing tasks more efficiently than a comparable 4-core processor.
3.2 CPU Manufacturers and Architectures
Two major manufacturers of desktop and laptop CPUs are:

1. Intel

Intel manufactures processors such as:
- Intel Core i3
- Intel Core i5
- Intel Core i7
- Intel Core i9
- Intel Core Ultra series
2. AMD

AMD manufactures processors such as:
- Ryzen 3
- Ryzen 5
- Ryzen 7
- Ryzen 9
- Ryzen Threadripper
Intel and AMD primarily use the x86 instruction set architecture in their mainstream PC processors.

Another important architecture is ARM.

3. ARM

ARM is an instruction set architecture used by processors in various devices, including:
- Smartphones
- Tablets
- Apple Mac computers
- Embedded systems
- Some servers
Examples include Apple's M-series processors and Qualcomm Snapdragon processors.
3.3 Types of CPU Architectures
There are three important architecture terms to understand:
Architecture	Description
x86 (32-bit)	Older 32-bit instruction set architecture
x86-64 (64-bit)	64-bit extension of the x86 architecture
ARM64 (AArch64)	64-bit ARM architecture


Important distinction:
- Intel and AMD primarily use x86-64 architecture in modern PCs.
- Apple Silicon uses ARM64 architecture.
- Qualcomm processors also use ARM-based architecture.
4. CPU Socket Types
A CPU socket is a physical connector on the motherboard where the processor is installed.

Different processors require compatible sockets.

Two common socket technologies are:
4.1 LGA (Land Grid Array)
LGA stands for Land Grid Array.

In this socket design:
- Electrical contact pins are located on the motherboard socket.
- The processor contains flat contact pads.
- The CPU is placed into the socket and secured.
Example: Many Intel desktop processors use LGA sockets.
4.2 PGA (Pin Grid Array)
PGA stands for Pin Grid Array.

In this design:
- Pins are located on the processor.
- The motherboard socket contains corresponding holes.
- The CPU pins fit into these holes.
Example: AMD's AM4 desktop platform uses PGA-style processors.

Important correction: AMD AM4 uses PGA, but AMD AM5 uses LGA. Therefore, not all AMD processors use PGA.
5. RAM (Random Access Memory)
RAM stands for Random Access Memory.

It is a temporary, high-speed memory that stores data and instructions currently being used by the CPU.

RAM acts as the computer's short-term workspace.
Characteristics of RAM
1. It is volatile memory.
2. Data is temporarily stored.
3. Data is lost when the computer is powered off.
4. It provides faster access to data than traditional storage devices.
5. It helps the CPU access currently required information quickly.
5.1 Types of RAM Based on Form Factor
RAM can be classified according to the device in which it is installed.

1. DIMM (Dual Inline Memory Module)
- Commonly used in desktop computers.
- Larger physical size than laptop RAM.
- DDR4 desktop DIMMs have 288 pins.
- DDR5 desktop DIMMs also have 288 pins.
- DDR3 desktop DIMMs have 240 pins.
2. SO-DIMM (Small Outline Dual Inline Memory Module)
- Commonly used in laptops and compact computers.
- Smaller than standard desktop DIMMs.
- DDR4 SO-DIMMs have 260 pins.
- DDR5 SO-DIMMs have 262 pins.
3. LPDDR (Low Power Double Data Rate)
- Commonly used in smartphones, tablets and thin laptops.
- Designed for low power consumption.
- Often soldered directly onto the motherboard.
- Generally not upgradeable by the user.
Examples include LPDDR4X and LPDDR5X.
5.2 Generations of RAM
RAM has evolved through different generations.

The most commonly discussed modern generations are DDR4 and DDR5.

DDR4 (Double Data Rate 4)

DDR4 is a fourth-generation SDRAM technology.

Characteristics:
- Common data rates: 2133–3200 MT/s.
- Desktop DIMM: 288 pins.
- Laptop SO-DIMM: 260 pins.
- Common capacities include 8 GB, 16 GB and 32 GB modules.
DDR5 (Double Data Rate 5)

DDR5 is the newer generation of mainstream DDR memory.

Characteristics:
- Standard starting data rate: 4800 MT/s.
- Higher-speed modules are available, including 5600, 6000, 6400 and 7200 MT/s.
- Desktop DIMM: 288 pins.
- Laptop SO-DIMM: 262 pins.
- Higher module capacities are available compared with earlier generations.
DDR4 vs DDR5
Feature	DDR4	DDR5
Generation	Fourth	Fifth
Starting standard speed	2133 MT/s	4800 MT/s
Common speeds	2133–3200 MT/s	4800–7200+ MT/s
Desktop pins	288	288
Laptop pins	260	262
Power voltage	1.2 V	1.1 V


Important: The maximum RAM capacity is not fixed at 64 GB for DDR4 or 256 GB for DDR5. It depends on the memory module, motherboard and CPU memory controller.

Also, DDR4 and DDR5 are not interchangeable because they have different electrical and physical designs.
6. Motherboard Form Factors
A motherboard form factor refers to its physical size, layout and mounting specifications.

There are three commonly discussed motherboard form factors.
6.1 ATX (Advanced Technology eXtended)
- Standard dimensions: 12 × 9.6 inches.
- Provides multiple expansion slots.
- Supports multiple storage and connectivity options.
- Commonly used in desktop PCs.
6.2 Micro-ATX
- Standard dimensions: 9.6 × 9.6 inches.
- Smaller than ATX.
- Usually has fewer expansion slots.
- Suitable for compact desktop computers.
6.3 Mini-ITX
- Standard dimensions: 6.7 × 6.7 inches.
- Very compact motherboard.
- Usually has one PCIe expansion slot.
- Commonly used in small-form-factor PCs.
Comparison
Feature	ATX	Micro-ATX	Mini-ITX
Size	12 × 9.6 inches	9.6 × 9.6 inches	6.7 × 6.7 inches
Expansion	More	Moderate	Limited
Physical size	Large	Medium	Small
Usage	Standard desktops	Compact desktops	Small PCs


Correction: The third form factor is called Mini-ITX, not Mini-ATX.
7. BIOS and CMOS Battery
7.1 BIOS (Basic Input/Output System)
BIOS stands for Basic Input/Output System.

It is firmware stored in non-volatile memory on the motherboard.

Its primary responsibility is to initialize hardware components and start the booting process when the computer is powered on.
Functions of BIOS
1. Performs POST (Power-On Self-Test).
2. Detects and initializes hardware components.
3. Checks essential hardware during startup.
4. Identifies bootable storage devices.
5. Starts the operating system boot process.
6. Provides basic hardware configuration options.
Note: Modern computers generally use UEFI firmware, which is the successor to traditional BIOS.
7.2 CMOS Battery
CMOS stands for Complementary Metal-Oxide-Semiconductor.

A small battery is installed on the motherboard to maintain the real-time clock and retain certain firmware settings when the computer is switched off and disconnected from power.
Functions of CMOS Battery
1. Maintains the system date and time.
2. Helps retain certain BIOS/UEFI settings.
3. Provides backup power to the real-time clock.
Example: If the CMOS battery becomes weak or dead, the computer may display an incorrect date and time or lose certain firmware settings.
8. Storage Devices
Storage devices are used to store data, applications, files and operating systems permanently.

Unlike RAM, storage devices are non-volatile, meaning they retain data even when the computer is powered off.

There are three important storage technologies to understand.
8.1 HDD (Hard Disk Drive)
HDD stands for Hard Disk Drive.

It is a traditional storage device that uses rotating magnetic disks to store data.

Characteristics:
- Uses magnetic storage technology.
- Contains moving mechanical parts.
- Generally offers large storage capacities.
- Slower than SSDs.
- More sensitive to physical shocks.
8.2 SSD (Solid State Drive)
SSD stands for Solid State Drive.

It uses flash memory to store data.

Characteristics:
- No moving mechanical parts.
- Faster than traditional HDDs.
- More resistant to physical shocks.
- Faster booting and application loading.
- Generally more expensive per GB than HDDs.
8.3 NVMe SSD
NVMe stands for Non-Volatile Memory Express.

It is a storage communication protocol designed specifically for high-speed storage devices.

NVMe SSDs generally communicate through the PCIe interface.

Characteristics:
- High data transfer speeds.
- Low latency.
- Efficient communication with the CPU.
- Commonly available in M.2 form factor.
Important distinction:

NVMe is not a separate physical storage technology from SSD. It is a protocol used by SSDs.

An SSD can use SATA or NVMe as its communication interface/protocol.
Comparison of Storage Devices
Feature	HDD	SATA SSD	NVMe SSD
Technology	Magnetic	Flash	Flash
Moving parts	Yes	No	No
Speed	Slow	Fast	Generally faster
Interface	SATA, etc.	SATA	PCIe
Cost per GB	Low	Medium	Generally higher


9. RAID (Redundant Array of Independent Disks)
RAID stands for Redundant Array of Independent Disks.

It is a technology that combines multiple physical storage drives into a logical storage system.

RAID is used to improve:
- Storage performance.
- Data redundancy.
- Fault tolerance.
- Storage availability.
There are several RAID levels, but three important ones discussed in your lecture are RAID 0, RAID 1 and RAID 5.
9.1 RAID 0 – Striping
RAID 0 uses a technique called data striping.

In data striping, data is divided into smaller blocks and distributed across multiple drives.

For example, if we have two 500 GB drives, RAID 0 combines them to provide 1 TB of usable capacity.

Characteristics:
- Minimum two disks required.
- Uses data striping.
- Improves read and write performance.
- 100% usable storage capacity.
- Zero fault tolerance.
Example:

If one drive fails, the entire RAID 0 array may become inaccessible because parts of the data are distributed across both drives.

Use case: Applications where speed is important and data loss is not a major concern.
9.2 RAID 1 – Mirroring
RAID 1 uses a technique called data mirroring.

In mirroring, identical copies of data are stored on two or more drives.

For example:

If we have two 500 GB drives, the same data is stored on both drives.

Although the total physical capacity is 1 TB, only 500 GB is usable.

Characteristics:
- Minimum two disks required.
- Uses data mirroring.
- 50% usable capacity with two equal-sized drives.
- Fault tolerance of one drive failure in a two-drive mirror.
- Provides data redundancy.
Example:

Suppose one drive fails due to hardware damage. The other drive still contains an identical copy of the data, allowing the system to continue operating.

Use case: Systems where data availability and redundancy are important.
9.3 RAID 5 – Striping with Distributed Parity
RAID 5 combines data striping with distributed parity.

It requires a minimum of three drives.

To understand RAID 5, we first need to understand parity.
What is Parity?
Parity is additional information calculated from data blocks and stored across the drives.

RAID 5 uses XOR (Exclusive OR) calculations to generate parity information.

This parity information helps reconstruct missing data if one drive fails.

Unlike RAID 1, RAID 5 does not store complete duplicate copies of the data.

Instead, it distributes data blocks and parity blocks across all drives.

Characteristics:
- Minimum three drives required.
- Uses data striping and distributed parity.
- Can tolerate one drive failure.
- Usable capacity equals (Number of drives − 1) × Capacity of the smallest drive.
- Provides a balance between storage efficiency and fault tolerance.
Example:

Suppose we have three 500 GB drives.

Total physical capacity = 1500 GB.

Usable capacity = (3 − 1) × 500 GB = 1000 GB.

The remaining 500 GB equivalent is used for distributed parity.

If one drive fails, the missing data can be reconstructed using the remaining data and parity information.
RAID Comparison Table
Feature	RAID 0	RAID 1	RAID 5
Minimum disks	2	2	3
Technique	Striping	Mirroring	Striping + Parity
Usable capacity	100%	50% (2 disks)	(N−1) disks
Fault tolerance	0	1 (2-drive mirror)	1
Performance	High	Good read performance	Good read performance
Main purpose	Speed	Redundancy	Balance


Important exam point: RAID is not a replacement for backup. RAID protects against certain drive failures, but it does not protect against accidental deletion, malware, theft or disasters.
10. Peripheral Devices and I/O Ports
Peripheral devices are external or additional hardware components connected to a computer to provide input, output or additional functionality.

Examples include:
- Keyboard
- Mouse
- Monitor
- Printer
- Speakers
- External storage devices
- Webcam
10.1 HDMI Port
HDMI stands for High-Definition Multimedia Interface.

It is used to transmit digital audio and video signals between devices.

Example: Connecting a computer to a monitor or television.
10.2 DisplayPort
DisplayPort is a digital display interface used to transmit audio and video signals.

It is commonly used in computer monitors and graphics cards.
10.3 USB Port
USB stands for Universal Serial Bus.

It is used to connect external devices and transfer data.

Examples:
- Keyboard
- Mouse
- Pen drive
- External hard disk
- Smartphone
10.4 RJ45 Port
RJ45 is commonly used to connect Ethernet cables to computers and networking devices.

It provides a wired network connection.

It is commonly used for:
- LAN (Local Area Network).
- Ethernet connectivity.
- Wired internet connections.
11. PCIe Expansion Slots
PCIe stands for Peripheral Component Interconnect Express.

It is a high-speed interface used to connect expansion cards to the motherboard.

These slots allow users to add additional functionality to their computers.
Common PCIe Devices
1. Graphics cards (GPU).
2. Network interface cards.
3. Wi-Fi and Bluetooth cards.
4. Sound cards.
5. Storage expansion cards.
PCIe Lane Configurations
PCIe slots come in different lane configurations:
- PCIe x1
- PCIe x4
- PCIe x8
- PCIe x16
The number indicates the number of PCIe lanes available.

For example, graphics cards commonly use PCIe x16 slots.

Advantages of PCIe:
- High-speed data transfer.
- Expandability.
- Supports multiple hardware devices.
- Provides communication between the motherboard and expansion cards.
